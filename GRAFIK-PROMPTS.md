# 🎨 Ubongo – Grafik-Prompts für GPT Image 2

Jeder Prompt ist **vollständig eigenständig**: Format, exakte Größe und
Transparenz stehen direkt im Prompt – einfach den kompletten Block kopieren
und einfügen, mehr ist nicht zu tun. Falls dein Tool zusätzlich Regler für
Bildgröße/Hintergrund anbietet, stelle sie passend ein (gleiche Werte wie im
Prompt) – doppelt hält besser.

**Falls die Sicherheitsprüfung einen Prompt ablehnt** („moderation_blocked“):
Das ist fast immer ein Fehlalarm. Denselben Prompt einfach ein zweites Mal
senden hilft oft schon. Die Prompts hier sind bereits entschärft (ohne
Reizwörter wie „Maskottchen“, „Familien-“, „junger …“, „…kopf“ – isolierte
Tierköpfe werden gern fälschlich als heikel eingestuft, deshalb sind die
Avatare als „Profilbild/Brustbild“ formuliert); blockt ein Prompt trotzdem,
einen beschreibenden Nebensatz weglassen und erneut versuchen.

**Tipps:** Alle Bilder möglichst in einer Sitzung nacheinander erzeugen
(einheitlicher Stil). Gefällt eines nicht, einfach neu generieren lassen.
Vor dem Speichern prüfen: kein Text im Bild, Motiv vollständig, bei
transparenten Bildern kein weißer Kasten. **Dateiname exakt übernehmen** –
die App erkennt die Bilder am Namen. Ablage: `public/img/` im Repository
(GitHub → „Add file → Upload files“) oder einfach an Claude schicken.
